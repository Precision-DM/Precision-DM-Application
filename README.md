# Precision-DM Application

This is an example of a web application for displaying summarized patient data this is stored following the Precision Oncology Core Data Model (Precision-DM).
The application uses Python Flask to show pages about patient information, sequencing assays, genomic variants, and ECOG Performance Status scores.

For more information about the Precision-DM, see https://github.com/Precision-DM/Precision-DM
